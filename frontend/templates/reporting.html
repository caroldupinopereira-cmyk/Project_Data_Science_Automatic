Tentang Report & Export

PDF Report

Laporan lengkap berformat PDF dengan statistik deskriptif, visualisasi, insight, dan rekomendasi. Cocok untuk presentasi dan dokumentasi resmi.

HTML Report

Laporan interaktif berbasis web — bisa dibuka di browser, responsive, collapsible sections, search, dan print-friendly.

Export Excel

Download data sebagai file .xlsx dengan autofilter dan auto-width kolom. Siap dibuka di Microsoft Excel atau Google Sheets.

Export CSV

Format universal yang kompatibel dengan semua tools analisis data seperti Python, R, SPSS, dan lainnya.

Export JSON

Format data untuk integrasi API dan web applications. Mendukung orientasi records, columns, atau split.

Tips: Gunakan tombol Preview untuk melihat data sebelum download. Status Raw/Cleaned akan mengikuti data source yang dipilih di atas.
